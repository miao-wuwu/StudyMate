# StudyMate — 全栈学习管理平台

StudyMate 是一个面向个人学习场景的全栈学习管理平台，帮助用户管理学习笔记、规划学习任务、记录每日打卡，并通过专注计时与学习统计追踪学习进度。

本项目使用 React + TypeScript 构建前端，使用 Python + FastAPI 构建后端，并通过 SQLite 持久化存储学习数据。项目主要用于学习和实践前后端分离开发、REST API 设计、数据库操作和前端状态管理。

## 项目功能

### 1. 学习笔记管理
- 新增、查看、编辑和删除学习笔记
- 搜索已有笔记
- 使用 SQLite 保存笔记数据

### 2. 学习任务管理
- 管理个人学习任务
- 辅助规划日常学习安排

### 3. 每日学习打卡
- 记录每日学习情况
- 通过打卡日历查看学习记录
- 统计连续打卡情况

### 4. 专注计时
- 使用计时功能辅助专注学习
- 帮助建立规律的学习习惯

### 5. 学习统计仪表盘
- 汇总学习相关数据
- 展示学习进度和统计信息

### 6. 成就徽章
- 通过成就界面展示学习过程中的阶段性成果

> 说明：以上功能介绍根据项目当前的开发记录整理。具体统计口径和成就解锁规则以实际代码实现为准。

## 本地运行

前端和后端需要分别启动，并保持各自的终端运行。

### 1. 启动后端

在项目根目录 `StudyMate` 中打开 PowerShell：

```powershell
.\.venv\Scripts\Activate.ps1
python -m uvicorn main:app --reload
```

后端启动后，可访问：

- 后端地址：<http://127.0.0.1:8000>
- API 文档：<http://127.0.0.1:8000/docs>

### 2. 启动前端

另开一个终端，进入前端目录：

```powershell
cd D:\StudyMate\frontend
npm install
npm run dev
```

根据终端输出打开 Vite 提供的本地开发地址，通常为：

<http://localhost:5173/>

### 3. 检查前端生产构建

在前端目录执行：

```powershell
npm run build
```

如果构建成功，说明前端代码通过了当前构建流程的检查。

## 数据存储

项目使用 SQLite 保存学习数据，数据库连接配置位于后端代码中。

本地数据库文件通常为项目根目录下的 `studymate.db`。该文件用于本地开发和数据持久化，不应当作为公开项目源码的一部分提交。

克隆项目后，首次运行时会根据后端的数据库初始化逻辑创建所需的数据表。具体表结构以当前后端模型代码为准。
